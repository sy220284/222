# 原版多步骤行为复验脚本

此目录只存**审阅过的执行逻辑**，用于在提交者自己的私有工作区动态运行冻结的 2.1.88 原版代码，绝不复制原版业务实现或密钥。

每份执行脚本：
1. 从 CLI 第一个参数读取真实原版模块绝对路径（Node 的 `process.argv[2]`），从标准输入读取整个黄金用例数组。
2. 真实 import 原版源模块；按每条用例的步骤执行调用、保存有序事件、错误及状态，按场景重置污染性全局状态。
3. 输出唯一的 JSON 数组 `[{ "id": "场景ID", "expected": 实际原版结果 }]`，和 `tests/source_parity/golden/*.json` 中的已冻结期望逐条比较，禁止预设返回黄金期望值冒充运行结果。
4. 原版调用失败、格式不合法、用例覆盖不完整、结果不同立即失败。私有原版仅由提交者的 `--source-root` 提供，所有公开提交里只保留测试脚本及可重现的行为观察。
5. 脚本在受控私有环境中运行，禁用外网及生产凭据；文件型副作用须在专用临时目录进行，禁止修改冻结的原版源码。

已落地样例：`command_lifecycle.mjs` 真实注册、更换和清空监听器，并按通知顺序记录回调事件。Rust 侧由 `src/bin/parity_command_lifecycle.rs` 调用生产模块，比对实际状态变更。
