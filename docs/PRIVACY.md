# 网络与隐私边界

本项目不包含环境扫描后向产品运营服务器汇报、行为分析、实验分组上报、错误遥测汇报和自动账号登录等通道。**这属于明确删除项，不纳入移植完成度。**

## 用户明确发起的外部连接

1. **模型请求**：只有实际调用当前选中的提供商时才会发送，包含当前轮历史、项目提示词、工具声明及必要的工具结果。当前实现通过 `ProviderProfile.base_url` 配置服务端点，不需要绑定任何固定服务。
2. **MCP 服务**：只有配置 `mcp_servers` 才会启动本地 stdio 子进程。第三方 MCP 服务进程自行决定是否访问网络，接入前需审查命令来源和权限。
3. **Hooks**：只有配置 `hooks` 才会运行用户指定的本地命令；用户指定的外部命令可以自行联网。
4. **Shell 工具**：只在审批授权后运行。Shell 具有机器权限，允许执行自定义联网命令；不声称 Shell 有网络隔离。
5. **Git**：只读 Git status/diff/log 不会主动进行 fetch/push。

## 不应存在的连接

- 无登录启动检查、产品控制面连接与遥测采集队列。
- 无用户设备指纹与使用行为事件上传。
- 无对原厂固定服务端的隐式诊断、错误或性能回传。
- 无向第三方自动发送本地会话文件的模块。

## 本地数据

`.atlas/sessions/*.json` 存储会话和工具结果；可能含源代码或敏感文本。不得将目录提交版本控制或向任何服务自动上传。用户自行负责备份和删除。

## 验证与限制

`tests/privacy.rs` 会扫描 `src/` 和依赖配置，防止已删除的原厂品牌／典型遥测设施重新出现。该测试不能证明所有插件或用户 Shell 命令不会联网；外部模型请求会根据用户的明确配置发送实际内容。

对原始包的审计范围在 `docs/FILE_PORT_MATRIX.md` 中按文件记录。原路径名只是源码迁移标识，不是运行时品牌名称。
